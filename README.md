## 5. Ответы на вопросы:
1. · Поле класса принадлежит объекту, существует всё время жизни объекта и доступно всем методам класса. Имеет значения по умолчанию.
· Переменная в функции создается при вызове функции, уничтожается после её завершения, доступна только внутри этой функции и требует обязательной инициализации перед использованием.

2. Это специальный метод класса, который автоматически вызывается при создании нового объекта. Нужен для инициализации полей объекта начальными значениями.

3. @override— это аннотация, которая сообщает компилятору, что мы переопределяем метод из родительского класса.
Если её убрать, код продолжит работать, но компилятор не проверит правильность сигнатуры метода, и код станет менее читаемым.

4. Статическое поле принадлежит самому классу, а не его экземплярам, и является общим для всех объектов.
В программе существует ровно одна копия этого поля

5. нижнее подчеркивание означает, что поле (или метод) является приватным.Доступ к нему возможен только внутри того же файла, из других файлов он не виден.
